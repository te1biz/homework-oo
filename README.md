# Homework 14.1 — Объектно-ориентированное программирование

Базовый модуль интернет-магазина для каталогизации товаров и категорий с подсчетом счетчиков экземпляров на уровне классов.

#python #oop #classes #атрибуты #типы_данных #создание_класса #class #init #конструктор_класса #self #pytest #fixtures #flake8 #poetry

---

## Описание проекта

В проекте реализованы базовые классы каталога интернет-магазина:

1. **Product** (src/classes.py):
   * name: название товара (str)
   * description: описание товара (str)
   * price: цена (float)
   * quantity: остаток на складе (int)

2. **Category** (src/classes.py):
   * name: название категории (str)
   * description: описание категории (str)
   * products: список товаров в категории (list)
   * category_count: счетчик общего числа категорий (атрибут класса)
   * product_count: счетчик общего числа товаров во всех категориях (атрибут класса)


## Установка и запуск

### 1. Установка зависимостей

poetry install
### 2. Демонстрационный запуск

poetry run python main.py
